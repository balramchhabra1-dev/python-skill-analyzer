# Python Skill Analyzer

A beginner Python project that analyzes a user's skills and identifies
which skills are found and which are missing.

## Features

- User input
- Skill matching
- Missing skill detection
- Case-insensitive matching
- JSON file handling
- File reading and writing
- Basic error handling

## Technologies

- Python
- JSON

## How to Run

Clone the repository and run:

```bash
python main.py
